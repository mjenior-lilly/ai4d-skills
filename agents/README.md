# agents/

System prompts for agents that operate across a full session rather than perform one bounded task.

## Files

- `SYSTEM.md` - the base policy for a CLI coding agent. It defines instruction precedence, investigation expectations, contract-first and minimal-change practices, verification requirements, handling of ambiguity and destructive operations, repository conventions, observability and sensitive-data rules, and response style.
- `judge.md` - a corpus-grounded benchmark judge for responses to entries generated by `commands/create-test-dataset.md`. It evaluates instruction compliance, factual accuracy, required-fact coverage, reasoning quality, relevance, and clarity against the entry's canonical answer, evidence, reasoning path, known negative responses, and optional domain context.

## How to use

Use `SYSTEM.md` as a complete system prompt when an agent has repository and shell access and is responsible for making narrowly scoped, verified engineering changes. Use `judge.md` in an evaluation pipeline whose benchmark items follow the schema produced by `commands/create-test-dataset.md`.
